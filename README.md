# BuildFFA Plugin v3.3 (1.8.8 Compatible)

BuildFFA plugin for **Minecraft 1.8.8** and all 1.8.x Spigot/CarbonSpigot servers.

**Created by Muvixo**
**Plugin author: VanSaMa**
**Made by PixelValley**

## Features

- **Infinite Food** - Food never decreases
- **Infinite Blocks** - Placed blocks restored to inventory
- **Kit Editor** - Players customize their own kits
- **Void Kill** - Death below configurable Y
- **High Limit** - No build/PvP above configurable Y
- **Auto Kit** - On join/respawn
- **Kill Tracking** - Kill counter with rewards
- **Block Decay** - Placed blocks disappear
- **No Fall Damage**
- **No Mob Spawn**
- **Auto-creates config.yml and folders**

## Commands

| Command | Description |
|---------|-------------|
| `/buildffa help` | Show help |
| `/buildffa kiteditor` | Open Kit Editor |
| `/buildffa kiteditor save` | Save kit |
| `/buildffa kiteditor cancel` | Cancel |
| `/buildffa kiteditor reset` | Reset kit |
| `/buildffa setvoid` | Set void Y level |
| `/buildffa sethighlimit` | Set high Y limit |
| `/buildffa creator` | Show credits |
| `/buildffa reload` | Reload config |

## Installation

1. Download the JAR
2. Place in `plugins/` folder
3. Start server — plugin auto-creates config

## Compatibility

- ✅ Minecraft 1.8.8 (Spigot / CarbonSpigot / PaperSpigot)
- ✅ Minecraft 1.8.9
